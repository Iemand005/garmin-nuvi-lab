# Native button dashboard

> Historical lab-stage notes. See the [current development guide](../../docs/development.md) for the working player and local setup.

NUVI / DESK uses the original board, LCD and touch input. Three RAM-only buttons: TAP +1 increments decimal count (000..999, saturates), RESET clears the count, COLOR toggles a swatch. It retains the proven sampling protocol, clipped crosshair, contact indicator, heartbeat, hardware guards and bounded timer/ADC waits. No firmware/flash/filesystem calls, no external actions or USB host communication. Counts/colors reset when the program restarts.

Contact uses two consecutive valid raw pairs (>50 on both axes) to acquire; four consecutive invalid pairs to release/rearm. This increases release qualification from the crosshair test. Candidate button captured at first accepted position, including zero for outside buttons; most recent accepted hit must match on release. Holding does not repeat; starting outside and sliding in cannot activate. Moving off and releasing cancels; moving away and back before releasing can activate the original button. Three or fewer invalid samples cannot create a new press. Pressure and physical release reliability remain experimental.

Hit rectangles inclusive: TAP x18..105, RESET116..203, COLOR214..301; y144..192 for all. Rounded visuals do not change rectangular hit testing. Same provisional map x=(113*ADC1//256)-59, y=307-(94*ADC0//256), clipped6..313/6..233. Local scratch20bytes stores contact/capture/count/color; no persistent settings. Old cursor patch restored before each frame; decimal count/swatch rendered before current marker, then contact and heartbeat. Decimal raster and whole-frame/state comparisons checked offline.

Build: python3 scripts/make_buttons_probe.py then python3 scripts/build_rectangle_probe.py --experiment buttons. Audit: python3 scripts/audit_buttons_probe.py. Standard15case hardware guard/timeout/frame/handoff suite,79 input pairs on each supported framebuffer covering holds, three-sample dropout, release rearming, cancellation, outside acquisition, isolated sample, color/reset and marker extremes. Four additional initial counts127/456/789/998 check all decimal glyphs and saturation. Synthetic instruction checks do not prove physical reliability.

Stage_buttons_probe.py defaults read-only and --install requires authorization, known SD UUID/Mac reader, prior crosshair hash and audited pinned candidate, fsync/readback. Never modifies Garmin internal storage. Normal ejection mandatory before physical removal. Physical test: hold TAP +1 two seconds (no increment while holding), lift (count advances once), repeat; test COLOR and RESET, then press TAP and drag outside before release (no increment). Film display. If storage remounts, normal-eject before reset. Remove SD before recovery RESET.
